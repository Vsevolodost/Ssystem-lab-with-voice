# Bora — прототип учебного сценария

Статический сайт для проверки оформления, знакомства, адаптивной мини-диагностики и первого занятия. Два локальных профиля сохраняются в localStorage этого браузера. Это не авторизация и не изоляция данных между пользователями устройства.

## Запуск

Из этой папки: `node preview.cjs`. Открыть http://127.0.0.1:8041.

## Реализовано

- Два локальных профиля, индивидуальные цели, опыт и время занятий.
- Короткая диагностика с изменением сложности и ранней остановкой. Не является оценкой CEFR или Celpe-Bras.
- Три шага первого занятия, обратная связь по вариантам ответа, сохранение попыток и заметки.
- Экран реального прогресса без вымышленных показателей.
- Фотографии предоставлены пользователем как референсы; право публичного/коммерческого использования не подтверждено.

## До запуска для двух реальных учеников

1. Добавить серверную авторизацию и индивидуальное хранение в БД, удаление данных и резервное копирование.
2. Подключить GigaChat только на сервере через переменные окружения; проверить качество pt-BR и русских объяснений.
3. Подобрать лицензированные записи носителей pt-BR, расшифровки и переводы. Синтетическая речь не подменяет записи носителей.
4. Провести редактуру уроков преподавателем pt-BR, расширить банк заданий и проверку самостоятельных ответов.
5. Добавить интервальное повторение и отдельную диагностику аудирования. Сейчас диагностика проверяет только выбор ответов.

Не вставлять API-ключи в HTML/JS или переписку. Прототип не вызывает платные API.

## Render

Web Service, Node.js. Root Directory: `brazil-portuguese`. Build: `node --check server.cjs && node check.cjs`. Start: `npm start`. Health Check: `/health`. Сервер слушает `0.0.0.0` и переменную `PORT`. Тариф Free. Конфигурация также сохранена в `render.yaml`.

Проверка перед развёртыванием: `npm test` (включает HTTP-проверки). Развёртывание пока не добавляет БД и защищённый вход: прогресс остаётся в браузере ученика. Перенос на новый домен не переносит localStorage со старого адреса.
